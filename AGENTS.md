# volo-flutter-utils

A Flutter utility library: the `volo_flutter_utils` package (this repository's root) with validators, extensions and helpers.

| Path | Holds |
|---|---|
| `lib/` | Utilities. Imports `package:flutter/material.dart` because of `TimeOfDay`; the rest is pure Dart. Barrel `lib/volo_flutter_utils.dart` → `lib/src/<section>/<file>.dart` |
| `tool/` | Index and doc generators (`agent_index.dart`, `component_docs.dart`) |
| `bin/` | Command shipped to products (`agent_index.dart`) |
| `doc/` | Generated index and per-utility docs (shipped with the package) |
| `example/` | A minimal usage example |

## Commands

- `make check` — the gate. Checks formatting, index, docs, analysis and tests, and fails when a file under `lib/src` is not exported from the barrel. The `pre-push` hook (lefthook, installed by `make setup`) runs it; there is no test CI, and GitHub Actions only publish.
- `make index` — rewrites the index block below, `doc/index.txt` and `doc/**/*.md`.

## Rules

- A utility is a function, extension or class in `lib/src/<section>/<file>.dart` (sections: `extensions`, `helpers`, `validators`), exported from the barrel `lib/volo_flutter_utils.dart`. Its test lives in `test/<section>/<file>_test.dart`.
- Every public declaration needs a `///` first sentence. The index and docs are built from it, and without it `make check` fails with `file:line name`. The first sentence of the first paragraph becomes the one-line index entry, so keep it to 90 characters including the period and put details in the second sentence (longer fails with `file:line name (N chars)`; an index block must stay under 8,000 characters).
- An index line is `<file>|<main declaration>: <first sentence>` and is grouped under a `[section]` line. The doc is `doc/<section>/<file>.md`.
- Never edit `doc/` by hand. Produce it with `make index`.
- Public classes carry the `V` prefix (`VValidator`, `VDevice`), and an extension on a core type is named `V<Type>Extension`.
- Tests that need a daylight-saving zone go in `test/extensions/datetime_dst_test.dart`, which `make test` also runs under `TZ=America/New_York`.

## volo_flutter_utils index

Generated by `make index` from the first sentence of each public declaration's doc comment; do not edit by hand. Before using a volo_flutter_utils API, find it here and read its doc file. Each entry's doc is `doc/<section>/<name>.md` (`[.]` is the doc folder itself). Other public classes, enums, styles and data classes in each folder are listed in its doc file. If nothing fits, say what you looked for first.

```text
[extensions]
datetime_extensions|VDateTimeExtension: Calendar comparisons and day, month boundaries for DateTime.
double_extensions|VDoubleExtension: Layout and range helpers for double.
int_extensions|VIntExtension: Range, padding, duration and Unix-time helpers for int.
map_extensions|VMapExtension: Search, typed lookup, filtering, merging and key picking for Map.
string_extensions|VStringExtension: Format checks and small conversions for String.
timeofday_extensions|VTimeOfDayExtension: Comparison and midnight-wrapping arithmetic for TimeOfDay.
[helpers]
v_delay|VDebouncer: Runs callback once calls have stopped for duration.
v_device|VDevice: Platform checks and a cached summary of the current device.
v_log|VLog: Prints tagged log lines with the caller's file location.
v_package|VPackage: Reads the running app's name, version and build number once and caches it.
[validators]
v_validator|VValidator: Synchronous input checks that return a VValidationResult.
```
